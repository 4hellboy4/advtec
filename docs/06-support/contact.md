# Contact

## Support channels

| Channel | Purpose | Contact |
|---------|---------|---------|
| Email | Bug reports, integration questions, feature requests | `api-support@lovinideas.com` |
| GitHub Issues | Bug reports, documentation feedback | [Open an issue](https://github.com/4hellboy4/advtec/issues) |
| Security email | Security vulnerability reports | `security@lovinideas.com` |
| Business email | Commercial licensing, partnerships, increased rate limits | `hello@lovinideas.com` |

## Bug report requirements

When reporting a bug, include the following information:

1. The request that produced the issue: HTTP method, URL, headers (with token redacted), and request body.
2. The expected response.
3. The actual response, including the full `error` object.
4. The timestamp of the request, used to locate the corresponding server logs.

## Security disclosure

Security vulnerabilities must not be reported through public issue trackers. Submit reports to `security@lovinideas.com`. The team acknowledges reports within 48 hours.

## API status

Real-time API status and incident history are available at [status.lovinideas.com](https://status.lovinideas.com).

## Documentation feedback

The documentation source is maintained in a public GitHub repository. Corrections and improvements are accepted as pull requests. See [Contributing to the documentation](/contributing).
