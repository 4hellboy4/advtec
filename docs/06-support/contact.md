# Contact

## Support

For everything else — questions, bug reports, feature requests:

- **Email:** api-support@lovinideas.com
- **GitHub Issues:** [open an issue](https://github.com/your-username/lovinideas-api-docs/issues)

When reporting a bug, please include:

1. What you tried (the full request — method, URL, headers, body).
2. What you expected.
3. What actually happened (the full response, with token redacted).
4. A timestamp, so we can find it in our logs.

## Security

Please **don't** open public issues for security vulnerabilities. Email **security@lovinideas.com** instead — we respond within 48 hours.

## Business inquiries

## Status
